# Пример формы для подрядчиков

Приложение на Node.js/Express предоставляет страницу в бело-голубых тонах, где подрядчик может заполнить данные. При отправке формы автоматически фиксируется дата и время входа на проверку, а данные сохраняются в `data.json`. Широкая белая форма разделена на две голубые колонки с пространством между ними. После отправки показывается уведомление в белом окне с голубой рамкой и кнопкой «Перейти к следующей». Страница адаптирована для мобильных устройств.

Поле **ГОД** заполняется в формате `дд.мм.гггг` и автоматически подставляет точки при вводе. К каждой заявке можно прикрепить файлы: они сохраняются на сервере в папке `uploads/<ID_заявки>/`. Для загрузки предусмотрено белое поле с голубой подписью «выбрать файл» — сюда можно перетащить документы или выбрать их вручную. Страница не отображает ранее сохранённые заявки, поэтому доступ к данным возможен только на стороне сервера.

## Запуск

```bash
npm install
npm start
```

Страница будет доступна по адресу [http://localhost:3000](http://localhost:3000).
