# Пример формы для подрядчиков

Приложение на Node.js/Express предоставляет страницу в бело-голубых тонах, где подрядчик может заполнить данные. При отправке формы автоматически фиксируется дата и время входа на проверку, а данные сохраняются в `data.json`. Широкая белая форма разделена на две голубые колонки с пространством между ними. После отправки показывается уведомление в белом окне с голубой рамкой и кнопкой «Перейти к следующей». Страница адаптирована для мобильных устройств.

Поле **ГОД** заполняется в формате `дд.мм.гггг` и автоматически подставляет точки при вводе. К каждой заявке можно прикрепить файлы: они сохраняются на сервере в папке `uploads/<ID_заявки>/`. Для загрузки предусмотрено белое поле с голубой подписью «выбрать файл» — сюда можно перетащить документы или выбрать их вручную. Страница не отображает ранее сохранённые заявки, поэтому доступ к данным возможен только на стороне сервера.

## Запуск

```bash
npm install
npm start
```

Страница будет доступна по адресу [http://localhost:3000](http://localhost:3000).

## Структура путей

> Все основные пути вычисляются в модуле [`server/config/paths.js`](server/config/paths.js). Именно он определяет, где искать данные, куда сохранять загрузки и откуда раздавать статические файлы.

- **Файл данных** — приложение по очереди проверяет несколько вариантов и использует первый существующий:
  1. Путь из переменной окружения `DATA_FILE_PATH` (можно передать как абсолютный, так и относительный от корня проекта).
  2. Каталог Windows, переданный через переменную `WINDOWS_DATA_ROOT` или файл `.env` (см. ниже): из него автоматически подставляется путь `ck/data.json`.
  3. Значение по умолчанию `C:\Users\User\SK\ck\data.json`.
  4. Репозиторный файл: `<корень_проекта>/data.json`.

- **Папка загрузок** — `uploads/` в корне проекта. Для каждой заявки создаётся подпапка с её идентификатором, куда попадают загруженные документы.

- **Публичные файлы** — директория `public/`. При запуске сервера Express раздаёт оттуда собранные HTML, стили и JavaScript-модули (например, `index.html`, `style.css`, каталог `js/`).

- **Корень проекта** — база для всех относительных путей. Его значение экспортируется как `ROOT_DIR`, что позволяет переиспользовать расчёт пути в других частях сервера.

При необходимости переопределить любой из путей достаточно обновить конфигурацию в `server/config/paths.js` или передать собственные значения через переменные окружения.

### Быстрая настройка путей через `.env`

Для удобства в корне проекта можно создать файл `.env` на основе шаблона [`.env.example`](.env.example). В нём доступны переменные:

- `WINDOWS_DATA_ROOT` — базовый каталог, где размещена папка `ck` с рабочим `data.json` (например, `D:\Projects\SK`).
- `DATA_FILE_PATH` — полный путь до конкретного файла данных, если нужно переопределить даже имя или расположение `ck`.

Файл `server/config/env.js` автоматически загружает переменные из `.env`, поэтому достаточно сохранить изменения и перезапустить сервер.
